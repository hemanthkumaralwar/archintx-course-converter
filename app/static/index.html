Good to know

A 2 × 3 course takes about 2 minutes to convert. The largest size takes much longer.

How course size is decided

Each lesson is about 30 minutes, so modules, lessons and duration are linked. They never conflict:

  1. All automatic: sized from the document's length (one lesson per ~3,000 characters, up to 8 × 8).
  2. Modules and lessons chosen: the duration is worked out for you and can't be set.
  3. Duration chosen: any count left on Automatic is fitted to the hours you chose.
  4. Limits: up to 30 modules, 8 lessons per module and 32 hours. If the hours don't divide evenly, the course comes out slightly longer.

If the AI service is busy, each step is tried again automatically. If a conversion still fails, start it again; the command line can also continue a stopped run.

Every course is checked against the schema before you can download it.
